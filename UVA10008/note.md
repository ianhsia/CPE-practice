# UVA10008 - What's Cryptanalysis?


## 題目簡述
- 輸入多行文字，統計所有英文字母`A~Z`出現的次數，不分大小寫。
- 按照出現次數由多到少輸出。
- 如果出現的次數相同則按照字母順序排序。
- 沒出現的字母不需要。

## 用到的觀念
- `cin.ingnore()`
    + 清除 cin >> N 後留下的換行字元。
- `isalpha()`
    + 判斷是否為字母。
- `tolower()`
    + 將英文字母統一轉成小寫。
- `static_cast<char>()`
    + 把數值索引轉回字母。

## 題型
- 字串處理

## 解題思路
1. 先讀入總共有幾行文字。
2. 使用 `getline()` 逐行讀取每一行字串。
3. 逐一檢查字串中的每個字元。
4. 如果是英文字母，就先統一轉成小寫。
5. 利用 `s[j] - 'a'` 將 `a~z` 對應到陣列 `0~25`。
6. 用 `abc[26]` 統計每個字母出現的次數。
7. 統計完成後，每次找出目前出現次數最多的字母。
8. 輸出該字母與次數後，將它的次數設成 `0`，避免再次被選到。
9. 重複找最大值，直到所有出現過的字母都輸出完。
10. 如果次數相同，因為是從 `A` 到 `Z` 的順序尋找，所以字母較前面的會先輸出。

## 易錯
- `cin >> N` 後面接 `getline()` 時，要先用 `cin.ignore()` 處理留下的換行。
- 統計時要忽略空格、數字和標點符號，只計算英文字母。
- 大小寫要視為同一個字母，所以先用 `tolower()` 統一。
- `s[j] - 'a'` 才能正確對應到 `abc[0] ~ abc[25]`。
- 題目要求輸出大寫字母，所以輸出時要使用 `'A'`。
- 找到最大值並輸出後，要把該位置設為 `0`，避免重複輸出。
- 次數相同時，要按照 `A ~ Z` 的順序輸出。
