# UVA118 - Mutant Flatworld Expolrers


## 題目簡述
- 給定一個矩形地圖與多台機器人的初始位置、方向及移動指令，模擬每台機器人的移動。若機器人因前進而離開地圖，則標記為LOST，並在該位置留下scent，之後其他機器人在相同位置、相同方向遇到相同情況時，會忽略該次前進指令。

## 題型
- 模擬

## 解題思路
1. 讀取資料
    先讀右上角座標(範圍)`(maxX , maxY)`
    每台機器再讀入：
    + `X`：目前x座標
    + `Y`：目前y座標
    + `direction`：目前方向(N、E、S、W)
    + `command`：移動指令字串(L、R、F)
2. 方向處理
    將方向轉成數字較方便處理：
    | 方向 | 數字 |
    |------|------|
    | N | 0 |
    | E | 1 |
    | S | 2 |
    | W | 3 |
    + `R`：方向+1(循環)
    + `L`：方向-1(循環)
    最後輸出時再轉回 N、E、S、W。
3. 逐一執行指令
4. 判斷是否出界
5. scent★★★
    必須包含座標及方向


## 易錯
- `F` 要先計算 `nextX`、`nextY`，不能直接修改 `x`、`y`。
- `scent` 要記錄座標和方向，不能只記錄座標。
