# UVA948 - Fibonaccimal Base


## 題目簡述
- 給定一個十進位正整數，將它轉換成 Fiboncci 進為表示法。
- 從最大的 Fibonacci 數開始判斷，有使用則記為`1`，沒有則記為`0`。
- 例如：`10 = 8 + 2`，所以表示為`10010(fib)`。

## 用到的觀念
- 暫存變數 `temp`
    + 保留原本的 `n`
    + 使用 `temp` 進行減法

## 題型
- 貪心法（Greedy）
    + 每次選擇目前最好的選擇。
    + `此題每次選擇不超過剩餘數值的最大 Fibonacci 數。`

## 解題思路
1. 建立 Fibonacci 數列
   + 從 `1、2` 開始。
   + 利用 `fib[i] = fib[i-2] + fib[i-1]` 產生後面的數字。

2. 找最大可用的 Fibonacci
   + 從小到大尋找。
   + 找到第一個 `fib[k] > n` 時，`fib[k-1]` 就是不超過 `n` 的最大 Fibonacci。
   + 用 `pos = k-1` 記錄位置。

3. 保留原本的 `n`
   + 使用 `temp = n` 來進行後面的減法。

4. 從 `pos` 往回判斷
   + 如果 `temp >= fib[L]`，代表可以使用這個 Fibonacci，輸出 `1` 並減掉它。
   + 否則輸出 `0`。

5. 輸出結果
   + 格式為：`n = 結果 (fib)`
   + 例如：`10 = 10010 (fib)`

## 易錯
- Fibonacci 起始值
  + 此題使用 `1, 2, 3, 5, 8...`
  + `fib[0] = 1`、`fib[1] = 2`

- `fib[i-1]`
  + `i` 是下一個準備計算的位置。
  + `i-1` 才是目前最後一個已算好的位置。

- 找最大 Fibonacci 時比較符號容易寫反
  + 要找 `<= n` 的最大 Fibonacci。
  + 找到第一個 `fib[k] > n` 時，答案位置是 `k-1`。

- `temp = n`
  + `temp` 存剩餘數值，不是存 `pos`。

- 倒著跑迴圈
  + `for(int L = pos; L >= 0; L--)`
  + 容易把 `>= 0` 寫成 `<= 0`。

- `fib[L]` 與 `fib[pos]` 不要搞混
  + 迴圈每次要判斷目前位置，所以使用 `fib[L]`。
