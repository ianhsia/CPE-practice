# UVA490 - Rotating Sentences


## 題目簡述
- 輸入多行文字，將整段文字順時針90度後輸出。
- 若長度不同則補空白。

## 用到的觀念
- `getline(cin,s)`
- `vector<string> str`
    + 建立一個可以存放多個 `string` 的 vector。
- `str.push_back(s)`
    + 將 `s` 加到 `str` 的最後面。

## 題型
- 字串處理
- 模擬

## 解題思路
1. 逐行讀取輸入
2. 儲存每一行(存在一起)
3. 依照字元位子逐列輸出
4. 每個位置都從最後一行往第一行取字元，達到順時針旋轉 90 度的效果。
5. 如果某一行沒有該位置的字元，就輸出一個空白補齊。
6. 每完成一次所有行的輸出後`換行`。

## 易錯
- `str.size()` 是資料數量，但索引從 `0` 開始，所以最後一行是 `str.size() - 1`。
- `i` 代表第幾行，`j` 代表第幾個字元，不要搞反。
- 取 `str[i][j]` 前，要先判斷 `j < str[i].length()`，避免超出範圍。
- 某一行沒有第 `j` 個字元時，要補空白，不能直接跳過。
- `cout << endl;` 要放在內層 `for` 結束後，不然會每印一個字就換行。
- 兩層 `for` 要放在 `while(getline(...))` 外面，先把所有行讀完再旋轉。
