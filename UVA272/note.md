# UVA272 - Tex Qutes


## 題目簡述
- 讀取多行文字直到 EOF，將每個普通雙引號 (`"`) 依序轉換為 TeX 引號格式：開始引號為 ``，結束引號為 ''，其餘文字維持不變。

## 用到的觀念
- getline(cin,s) s=string儲存的位子
    + 讀取一整行文字（包含空白）
- bool
    + 判斷

## 題型
- 字串處理

## 解題思路
1. 思考如何讀取資料(一整行)
2. 逐字檢查
3. 判斷是否為雙引號
4. 判斷開始還是結束★★★
5. 輸出

## 易錯
- 使用 `getline()`，不要用 `cin >>`。
- `bool open` 要放在 `while` 外。
- 使用 `while(getline(cin, s))`，不用 `cin.eof()`。
- `s[i]` 是單一字元，不能直接改成 `"``"` 或 `"''"`。
- 每行處理完記得輸出換行。
